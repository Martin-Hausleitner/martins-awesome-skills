# Private Setup Boundary

This repository intentionally does not expose the private OpenClaw/Hermes setup it came from.

## Not Included

- real gateway configuration
- real Telegram bot tokens or chat ids
- local OpenClaw workspace memory
- Hermes sessions, trajectories, or imports
- account-specific automation
- personal health/location/chat/clipboard/accounting workflows
- local machine names, private paths, and service topology

## Included Instead

- reusable skills
- placeholder-based config templates
- fake/local tests
- public-safe documentation
- a safety audit script

## Why

Agent skills are useful when they are portable. Private operations are useful when they stay private. This repo keeps those two concerns separate.
